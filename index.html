Clima
Como funciona
01

Relógio do sistema

Zero latência. O horário vem diretamente do seu dispositivo e é atualizado exatamente a cada segundo via JavaScript.

02

Cálculo matemático de fusos

Os offsets UTC são calculados diretamente, sem depender de nenhuma API externa para os horários globais.

03

Clima via Open-Meteo

Temperatura e código WMO de cada cidade buscados da API gratuita Open-Meteo com coordenadas de precisão.

04

Globo em Canvas 2D

Mapa-múndi animado em 3D renderizado frame a frame usando a API nativa Canvas do browser com dados TopoJSON reais.
